# 板端指标与日志调整

## Goal
在不改变业务协议和处理结果的前提下，为板端 SL-LinkA、地图生成和 Super-LIO 生命周期加入低开销指标与中文注释，并提供可控导出。

## Phases
- [complete] 定位现有日志、地图分片和模式切换路径。
- [complete] 实现有界指标注册表与 JSON 导出，并接入现有日志配置。
- [complete] 添加协议、地图、生命周期埋点和中文注释。
- [complete] 运行单测、语法检查与差异检查。

## Constraints
- 仅改板端；APP 留到后续。
- 不逐帧写磁盘，不记录载荷内容。
- 保留已有 ROS 警告和错误日志。
- 不改动用户现存的 Super-LIO 子仓库变更及 artifacts 临时文件。
- 各 ROS 进程各有独立指标注册表；独立系统采样节点无法直接读取其他进程的内存计数器，先由每个进程自行导出指标。
